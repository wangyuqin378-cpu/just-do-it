# Just Do It

[English](README.md) · [工作流示例](EXAMPLES.md)

**把一句任务请求整理成可跟踪、可执行的工作计划。**

面向希望研究 Agent 如何接收任务、选择工作流、保留执行结果的人。仓库包含 Skill 指令和文档模板，不是独立应用。

**当前阶段：工作流实验。** 原始流程依赖内部工作平台、身份配置和组织服务，不能作为通用公开工具直接安装运行。查看示例不需要服务权限，执行原始流程需要。

## 从哪里开始

1. 阅读 [EXAMPLES.md](EXAMPLES.md)，了解输入请求和预期过程。
2. 阅读 [SKILL.md](SKILL.md)，核对路由规则、运行前提和执行行为。
3. 查看[个人任务格式](TODO_LIST_FORMAT.md)、[共享任务格式](SHARE_LIST_FORMAT.md)和[文档模板](DOC_TEMPLATES.md)。
4. 适配外部环境前，先阅读[降级行为](FALLBACKS.md)与[路由扩展](ROUTE_EXTENSIONS.md)。

典型过程是：**收到请求 → 建立任务记录 → 按需确认 → 执行 → 返回结果或安排后续处理**。内部 CLI、用户身份变量与对应服务不随此仓库提供，因此没有一条能在任意环境完成安装并运行的命令。
